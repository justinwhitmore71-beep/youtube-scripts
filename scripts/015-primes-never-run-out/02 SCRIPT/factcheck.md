# Fact-check: why the primes never run out (both scripts)

| # | Claim | Source 1 | Source 2 | Status |
| --- | --- | --- | --- | --- |
| c1 | A prime is a whole number greater than 1 whose only factors are 1 and itself (2, 3, 5, 7, ...). | [OpenStax, Contemporary Mathematics, §1.1 Basic Set Concepts (Rice University)](https://github.com/openstax/osbooks-contemporary-mathematics/blob/main/modules/m00011/index.cnxml): "A prime number is a natural number greater than 1 that is only divisible by one and itself." | [OpenStax, Intermediate Algebra 2e, §1.1 Use the Language of Algebra (Rice University)](https://github.com/openstax/osbooks-prealgebra-bundle/blob/main/modules/m81422/index.cnxml): "A prime number is a counting number greater than 1 whose only factors are 1 and itself." | OK |
| c2 | Every whole number greater than 1 is a product of primes, so it has at least one prime factor. | [OpenStax, Contemporary Mathematics, §3.1 Prime and Composite Numbers (Rice University)](https://github.com/openstax/osbooks-contemporary-mathematics/blob/main/modules/m00041/index.cnxml): "Every natural number, other than 1, can be expressed in exactly one way, apart from the arrangement, as a product of primes." | [Judson, Abstract Algebra: Theory and Applications, §2.2 The Division Algorithm: Prime Numbers (Stephen F. Austin State University)](https://github.com/twjudson/aata/blob/master/src/integers.xml): "Let n be an integer such that ... Then ... where ... are primes (not necessarily distinct)." | OK |
| c3 | There are infinitely many primes: for any finite list of primes, N = (their product) + 1 leaves remainder 1 when divided by each of them, so its prime factors (c2) are not on the list. | Proven on screen: if p1, ..., pn were all the primes, N = p1·p2·...·pn + 1 is greater than 1, and dividing N by any pi leaves remainder 1, so no pi divides N. By c2, N has a prime factor, which is therefore not in the list. Contradiction, so no finite list contains every prime. | - | PROOF |
| c4 | Worked example: 2 × 3 × 5 × 7 + 1 = 211, which leaves remainder 1 when divided by 2, 3, 5 and 7, and is itself prime; but 2 × 3 × 5 × 7 × 11 × 13 + 1 = 30,031 = 59 × 509 is not prime. | Arithmetic shown on screen: 2·3·5·7 = 210, + 1 = 211; 211 = 2·105 + 1 = 3·70 + 1 = 5·42 + 1 = 7·30 + 1; 211 has no factor among 2, 3, 5, 7, 11, 13 (and 17² > 211), so it is prime. 2·3·5·7·11·13 = 30,030, + 1 = 30,031 = 59 × 509. | - | PROOF |

Notes: The same proof appears in Judson, AATA §2.2 (theorem titled 'Euclid'): 'Hence, either P is prime or there exists an additional prime number p ≠ p_i that divides P.' Not naming Euclid in the script because only that one source was opened for the attribution. Levin's Discrete Mathematics has this proof in its source file, but it is commented out of the published book, so it is not cited.
