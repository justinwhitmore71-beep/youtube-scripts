## Description
Suppose you had a complete list of primes. Multiply them all and add one: dividing that number by any prime on the list leaves remainder 1, so none of them divides it. But every number above 1 has a prime factor, so a prime is missing from the list. No list is ever complete, so the primes never run out.

## Pinned comment (suggested)
The 'product + 1' number isn't always prime itself: 2×3×5×7×11×13 + 1 = 30,031 = 59 × 509. The proof only needs its prime factors to be NEW, and 59 and 509 aren't on the list.
