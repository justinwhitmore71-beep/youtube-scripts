# Brief: why the primes never run out

Series: Simple Proofs
Idea: Multiply every prime on any finite list and add one: the result leaves remainder 1 when divided by each prime on the list, but it must have a prime factor, so some prime is missing from the list; no list can be complete.
Misconception: Primes get rarer as numbers grow, so eventually they must run out.
Hook angle: Primes never run out, and the proof fits in one multiplication.
Narrowed to: The classic multiply-and-add-one proof only. No prime number theorem, no gaps between primes, no history.
Key condition to say aloud: Uses the fact that every whole number above 1 has at least one prime factor.
Candidate sources: OpenStax, Contemporary Mathematics, §1.1 Basic Set Concepts (Rice University) (https://github.com/openstax/osbooks-contemporary-mathematics/blob/main/modules/m00011/index.cnxml); OpenStax, Intermediate Algebra 2e, §1.1 Use the Language of Algebra (Rice University) (https://github.com/openstax/osbooks-prealgebra-bundle/blob/main/modules/m81422/index.cnxml); OpenStax, Contemporary Mathematics, §3.1 Prime and Composite Numbers (Rice University) (https://github.com/openstax/osbooks-contemporary-mathematics/blob/main/modules/m00041/index.cnxml); Judson, Abstract Algebra: Theory and Applications, §2.2 The Division Algorithm: Prime Numbers (Stephen F. Austin State University) (https://github.com/twjudson/aata/blob/master/src/integers.xml)
Originality: Usually written as a formal proof by contradiction. Ours makes it a challenge ('hand me your complete list') and B runs it on a real list (2, 3, 5, 7 gives 211), with the pinned comment heading off the most common misreading.
Not used: Naming Euclid (only one source opened here: Judson's AATA); the prime number theorem; 'N is always prime' (false, see pinned comment).
