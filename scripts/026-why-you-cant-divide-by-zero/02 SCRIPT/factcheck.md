# Fact-check: why you can't divide by zero (both scripts)

| # | Claim | Source 1 | Source 2 | Status |
| --- | --- | --- | --- | --- |
| c1 | Dividing a number by zero is undefined (it has no answer). | [OpenStax, Prealgebra 2e, §1.4 Divide Whole Numbers (Rice University)](https://github.com/openstax/osbooks-prealgebra-bundle/blob/main/modules/m81256/index.cnxml): "Division by zero is said to be undefined." | [OpenStax, Elementary Algebra 2e, §1.8 Properties of Real Numbers (Rice University)](https://github.com/openstax/osbooks-prealgebra-bundle/blob/main/modules/m82460/index.cnxml): "We conclude that there is no answer to 4 ÷ 0 and so we say that division by 0 is undefined." | OK |
| c2 | Division undoes multiplication, so a ÷ 0 would have to be a number that gives a when multiplied by 0. | [OpenStax, Prealgebra 2e, §1.4 Divide Whole Numbers (Rice University)](https://github.com/openstax/osbooks-prealgebra-bundle/blob/main/modules/m81256/index.cnxml): "Now suppose that we want to divide $10 by 0 . That means we would want to find a number that we multiply by 0 to get 10 ." | [OpenStax, Elementary Algebra 2e, §1.8 Properties of Real Numbers (Rice University)](https://github.com/openstax/osbooks-prealgebra-bundle/blob/main/modules/m82460/index.cnxml): "there a number that multiplied by 0 gives 4?" | OK |
| c3 | Any number times zero is zero, so no number times 0 can give 10. | [OpenStax, Prealgebra 2e, §1.4 Divide Whole Numbers (Rice University)](https://github.com/openstax/osbooks-prealgebra-bundle/blob/main/modules/m81256/index.cnxml): "This cannot happen because 0 times any number is 0 ." | [OpenStax, Elementary Algebra 2e, §1.8 Properties of Real Numbers (Rice University)](https://github.com/openstax/osbooks-prealgebra-bundle/blob/main/modules/m82460/index.cnxml): "Since any real number multiplied by 0 gives 0, there is no real number that can be multiplied by 0 to obtain 4." | OK |
| c4 | 'Infinity' is not the answer either: 1/x grows without bound as x approaches 0 from the positive side but goes to minus infinity from the negative side, so there is no single limit. | [OpenStax, Calculus Volume 1, §2.2 The Limit of a Function (Rice University)](https://github.com/openstax/osbooks-calculus-bundle/blob/main/modules/m53491/index.cnxml): "Since limx→0 - 1x = -∞ and limx→0 + 1x = +∞ have different values, we conclude that limx→01xDNE." | [APEX Calculus, §1.6 Limits Involving Infinity (Hartman et al., Virginia Military Institute)](https://github.com/APEXCalculus/APEXCalculus_Source/blob/master/text/01_Limits_Involving_Infinity.tex): "It is easy to see that the function grows without bound near 0, but it does so in different ways on different sides of 0." | OK |
| c5 | Division can be read as repeated subtraction (how many 3s fit in 12); subtracting 0 never changes the total, so 'how many zeros fit' has no answer. | Shown on screen: 12 − 3 − 3 − 3 − 3 = 0, so four 3s fit in 12 (and 4 × 3 = 12); 12 − 0 − 0 − ... stays 12 forever, so no count of zeros ever empties it. | - | PROOF |

Notes: Prealgebra 2e and Elementary Algebra 2e are separate OpenStax books (overlapping author team); the playbook accepts different books, but Justin may want a non-OpenStax second source for c1 to c3. c5 (used in B) is shown on screen; Prealgebra 2e §1.4 gives the same argument: 'Another way to explain why division by zero is undefined is to remember that division is really repeated subtraction. How many times can we take away 0 from 10 ? Because subtracting 0 will never change the total, we will never get an answer.' 'DNE' in the Calculus quote means 'does not exist'.
