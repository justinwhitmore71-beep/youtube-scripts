## Description
Division undoes multiplication: 10 ÷ 2 = 5 because 5 × 2 = 10. So 10 ÷ 0 asks what number times 0 makes 10, and since anything times 0 is 0, no number works. Infinity doesn't work either: dividing by tiny positive numbers sends the answer up, tiny negative numbers send it down. That's why division by zero is undefined.

## Pinned comment (suggested)
And 0 ÷ 0? It fails for the opposite reason: 'what times 0 makes 0?' has every number as an answer, so there's still no single value. 'Undefined' means 'no one answer', not 'a forbidden answer'.
