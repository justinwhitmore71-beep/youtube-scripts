[HOOK] Six heads in a row is exactly as likely as five heads and then a tail. {c3}
[MASCOT: No way, six heads is rarer!] Surely all heads is the rarer one?
Each flip has a one in two chance, whatever came before. {c2}
[EQUATION: (1/2)⁶ = 1/64] So any exact six-flip sequence has a one in sixty-four chance. {c3}
They share the first five heads, and differ only in the last, fifty-fifty flip. {c3}
Expecting tails to be due is called the gambler's fallacy. {c1}
[TAKEAWAY] The coin has no memory, so a streak never changes the next flip. {c2}
