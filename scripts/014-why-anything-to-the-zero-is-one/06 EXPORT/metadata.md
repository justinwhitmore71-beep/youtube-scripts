## Description
Divide five cubed by five cubed: every copy cancels, leaving 1. But dividing powers subtracts the exponents, 3 − 3 = 0, giving five to the power zero. Both describe the same division, so 5⁰ = 1, and the same works for any number except zero.

## Pinned comment (suggested)
This works for every number except zero: 0⁰ is a special case that the textbooks leave undefined. For any other base, x⁰ = 1 isn't an arbitrary rule; dividing forces it.
