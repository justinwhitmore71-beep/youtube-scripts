[MASCOT: Same gap? No way!] Surely Earth's gap would be microscopic?

[EQUATION: C = 2πr  →  r = C / 2π] Circumference is two pi times radius, so radius is length over two pi. {c1}
Add one meter of length, and the radius grows by one over two pi: about sixteen centimeters. {c3}
The planet's size cancels out, so the basketball gets the same gap. {c3}
