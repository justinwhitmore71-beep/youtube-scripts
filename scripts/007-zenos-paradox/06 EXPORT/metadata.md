## Description
To cross a room you first go halfway, then half the rest, then half again: infinitely many steps. But the pieces 1/2 + 1/4 + 1/8 + ... add up to exactly 1, because the gap left always equals the last piece and halves toward zero. At a steady speed the times add up the same way, so you arrive.
