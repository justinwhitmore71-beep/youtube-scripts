# Script A: Sideways buys no airtime
Series: Everyday Physics
Angle: the wrong guess is 'the thrown one stays up longer'

[HOOK] Drop one ball and throw another sideways at the same moment: they land together. {c1}
[MASCOT: Surely the fast one flies longer?] Doesn't the thrown ball stay up longer?
Ignoring air, gravity only pulls down, and it pulls both the same. {c2}
Sideways speed carries the thrown ball farther, but adds nothing to its fall. {c1}
[EQUATION: y = ½ g t²] Both fall one half g t squared in the same time. {c3}
So the thrown ball just lands farther away, at the very same instant. {c1}
[TAKEAWAY] Sideways and downward motion are separate, so sideways speed never buys airtime. {c1}
