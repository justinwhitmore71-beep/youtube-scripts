## Description
Drop one ball and throw another exactly sideways from the same height at the same moment: they hit the floor together. Gravity only pulls down, and pulls both the same, so both fall ½gt² in the same time. The sideways speed changes where the thrown ball lands, not when. This ignores air resistance and assumes level ground.

## Pinned comment (suggested)
This is for a throw that's exactly sideways. Throw it upward at an angle and it does stay up longer, because now it starts with some upward speed. It also ignores air resistance, so real balls can differ slightly.
