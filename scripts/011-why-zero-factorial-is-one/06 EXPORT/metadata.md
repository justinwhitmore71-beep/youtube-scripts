## Description
Each factorial is its number times the one below: n! = n × (n − 1)!. So walking down the staircase means dividing: 4! = 24, 3! = 6, 2! = 2, 1! = 1, and one more step gives 0! = 1 ÷ 1 = 1. It's also the only value that keeps the counting formula n!/(n − r)! correct.

## Pinned comment (suggested)
"Isn't it just a convention?" Mathematicians do define 0! = 1, but not at random: it's the only value that keeps n! = n × (n − 1)! true at n = 1 and keeps the counting formulas right. Any other value would break both.
