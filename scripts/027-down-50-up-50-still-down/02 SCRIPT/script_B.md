# Script B: Up, then down, then cheaper
Series: Simple Proofs
Angle: the same trap in the other order
Suggested [MINE] line: line 5 (rewrite it in your own words, or keep it, and put [MINE] at its start; keep its beat words so the animation still lands)
---
[HOOK] Raise a price fifty percent, then cut it fifty percent, and it ends up cheaper. {c3}
[MASCOT: Up and down the same?] Wait, same percent up and down?
Each percent is taken of the current price. {c1} {c2}
[EQUATION: 100 × 1.5 × 0.5 = 75] A hundred dollars rises to one fifty; half of that is seventy-five. {c3}
That cut was half a bigger number, so it removed more than the raise added. {c3}
Either order ends at seventy-five: one point five times a half is three quarters. {c3}
[TAKEAWAY] Percent changes multiply rather than add, so equal ups and downs never cancel. {c3}
