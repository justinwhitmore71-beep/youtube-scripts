1[HOOK] A clock moving past you really ticks slower, and a bouncing light beam shows why.

2[MASCOT: Moving can't change time!] Come on, how can moving change time?

3 Light bouncing between two mirrors makes a clock: one bounce, one tick.

4 Moving past you, its light zigzags along a longer, slanted path.

5 Light's speed never changes, so a longer path means a longer tick.

6[EQUATION: Δt = Δτ / √(1 − v²/c²)] Pythagoras on the slanted path's triangle stretches each tick by this factor.

7[TAKEAWAY] Light's speed is fixed, so time stretches instead, though only near light speed does it show.

Script B

The triangle inside time

equation first, then the triangle that makes it
85 words, about 38 s

1[HOOK] Moving clocks run slow, and the proof is one triangle.

2[MASCOT: Time isn't stretchy!] Time can't stretch, can it?

3 Light bouncing between two mirrors is a clock: one round trip, one tick.

4 Watched moving, the light takes a slanted path, a triangle's long side.

5 Light's speed is the same for everyone, so the slanted trip must take longer.

6[EQUATION: Δt = Δτ / √(1 − v²/c²)] Pythagoras gives it: delta t equals delta tau, over root one minus v squared over c squared.

7[TAKEAWAY] At everyday speeds that bottom is almost one, which is why you never notice.
