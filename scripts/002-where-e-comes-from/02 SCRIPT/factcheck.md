| c1 | One dollar at 100% interest for one year, with interest added n times, grows to (1 + 1/n)^n dollars: $2 once a year, about $2.61 monthly, about $2.71 daily, about $2.718 once per second. | [OpenStax, Algebra and Trigonometry 2e, §6.1 Exponential Functions (Rice University)](https://github.com/openstax/osbooks-college-algebra-bundle/blob/main/modules/m49361/index.cnxml): "Examine the value of $1 invested at 100% interest for 1 year, compounded at various frequencies" | [OpenStax, Calculus Volume 1, §1.5 Exponential and Logarithmic Functions (Rice University)](https://github.com/openstax/osbooks-calculus-bundle/blob/main/modules/m53481/index.cnxml): "if the money is compounded n times per year, the amount of money in the account after t years is given by the function" | OK |
| c2 | As n grows, (1 + 1/n)^n levels off at the number e, about 2.718; it never passes it. | [OpenStax, Algebra and Trigonometry 2e, §6.1 Exponential Functions (Rice University)](https://github.com/openstax/osbooks-college-algebra-bundle/blob/main/modules/m49361/index.cnxml): "as n gets larger and larger, the expression ... approaches a number used so frequently in mathematics that it has its own name: the letter e" | [OpenStax, Calculus Volume 1, §1.5 Exponential and Logarithmic Functions (Rice University)](https://github.com/openstax/osbooks-calculus-bundle/blob/main/modules/m53481/index.cnxml): "In fact, ( 1 + 1 / m ) m does approach some number as m → ∞ . | c3 | Interest added continuously (nonstop) gives growth A = Pe^(rt), and base-e exponentials are used for many real-world growth models. | [OpenStax, Algebra and Trigonometry 2e, §6.1 Exponential Functions (Rice University)](https://github.com/openstax/osbooks-college-algebra-bundle/blob/main/modules/m49361/index.cnxml): "The letter e is used as a base for many real-world exponential models." | [OpenStax, Calculus Volume 1, §1.5 Exponential and Logarithmic Functions (Rice University)](https://github.com/openstax/osbooks-calculus-bundle/blob/main/modules/m53481/index.cnxml): "Since functions involving base e arise often in applications, we call the function f ( x ) = ex the natural exponential function." | OK |

Notes: Derived values (1 + 1/n)^n: n = 1: 2; n = 12: 2.613035; n = 365: 2.714567; n = 31,536,000 (seconds in a year): 2.718282 (all four match the table in Algebra and Trigonometry 2e §6.1). 'Never passes it': the values increase with n toward e, so every finite n stays below 2.718282...; the Mooculus page (e = lim (1 + 1/n)^n) and APEX Calculus §8.1 ('lim b_n = e' for b_n = (1 + 1/n)^n) state the same limit. 'Under two seventy-two' is safe because e = 2.71828... < 2.72. Quotes from the books' official source files on GitHub; formula symbols appear as plain text where the source uses math markup.
