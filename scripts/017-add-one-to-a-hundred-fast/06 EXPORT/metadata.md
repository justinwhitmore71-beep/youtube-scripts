## Description
Pair the ends of 1 + 2 + … + 100: 1 + 100, 2 + 99, 3 + 98 all make 101, because moving inward one number goes up by one while the other goes down by one. Fifty pairs of 101 is 5050. The same trick gives n(n + 1)/2 for the numbers 1 to n.

## Pinned comment (suggested)
If the list has an odd number of terms (say 1 to 99) there's a middle number with no partner, but the forward-and-backward version still works: 99 columns of 100, halved, is 4,950.
