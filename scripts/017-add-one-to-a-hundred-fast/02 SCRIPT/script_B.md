[HOOK] One to a hundred adds to five thousand fifty, and one picture shows why. {c1}
[MASCOT: Did someone add them all?] Did someone really add them one by one?
Write the numbers forward, then backward underneath. {c3}
[EQUATION: 1 + 2 + ... + n = n(n + 1)/2] Each column, one over a hundred, two over ninety-nine, adds to a hundred and one. {c3}
A hundred columns of a hundred and one is ten thousand one hundred. {c3}
That's the sum written twice, so halve it: five thousand fifty. {c3} {c1}
