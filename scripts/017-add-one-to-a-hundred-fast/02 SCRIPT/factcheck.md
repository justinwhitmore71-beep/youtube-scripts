# Fact-check: why 1 + 2 + ... + 100 = 5050 (both scripts)

| # | Claim | Source 1 | Source 2 | Status |
| --- | --- | --- | --- | --- |
| c1 | 1 + 2 + 3 + ... + 100 = 5050: pairing 1 + 100, 2 + 99, 3 + 98, ... gives 50 pairs that each add to 101. | [Levin, Discrete Mathematics: An Open Introduction, Sequences chapter, section 'Rate of Growth' (University of Northern Colorado)](https://github.com/oscarlevin/discrete-book/blob/main/source/sec_seq-growth.ptx): "we regroup and add 1+100 = 101. The next pair to combine is 2+99 = 101. Then 3+98 = 101. Keep going. This gives 50 pairs which each add up to 101" | [Ohio State University, Mooculus Calculus, Sigma notation](https://github.com/mooculus/calculus/blob/master/approximatingTheAreaUnderACurve/digInSigmaNotation.tex): "This is the sum 1+2+3+ ... + 100. According to Formula 2 above" | OK |
| c2 | The same idea works for any evenly spaced (arithmetic) list: sum = (number of terms) × (first + last) / 2; for 1 to n, n(n + 1)/2. | [OpenStax, Algebra and Trigonometry 2e, §13.4 Series and Their Notations (Rice University)](https://github.com/openstax/osbooks-college-algebra-bundle/blob/main/modules/m49447/index.cnxml): "The formula for the sum of the first n terms of an arithmetic sequence is S n = n( a 1 + a n ) 2" | [Levin, Discrete Mathematics: An Open Introduction, Sequences chapter, section 'Rate of Growth' (University of Northern Colorado)](https://github.com/oscarlevin/discrete-book/blob/main/source/sec_seq-growth.ptx): "In general, using this same sort of regrouping, we find that" | OK |
| c3 | Why every pair (or column) is 101: moving one step inward, the left number goes up by 1 and the right number goes down by 1. Writing the sum forward and backward gives 100 columns of 101 = 10,100 = twice the sum, so the sum is 5050. | Proven on screen: pair k is k + (101 − k) = 101 for k = 1 to 50. Forward/backward: S = 1 + 2 + ... + 100 and S = 100 + 99 + ... + 1; adding column by column, 2S = 100 × 101 = 10,100, so S = 5050. | - | PROOF |

Notes: c1 source 2 (Mooculus) goes on to compute 100(101)/2 = 5050 with its sum formula. c2: Algebra and Trigonometry 2e §13.4 derives the formula by the same forward-and-backward trick ('2 S n = n( a 1 + a n )'); Levin's sentence continues 'T_n = n(n+1)/2'. The anecdote about Gauss doing this as a schoolboy is in Levin only ('usually attributed to Carl Friedrich Gauss'), so it is not used.
