## Description
Suppose √2 were a fraction a/b in lowest terms. Squaring gives a² = 2b², so a is even; write a = 2k, and then b² = 2k², so b is even too. But then a/b wasn't in lowest terms, a contradiction. So no fraction equals √2: it's irrational, and its decimal never ends or repeats.

## Pinned comment (suggested)
Fractions can get as close to √2 as you like (1.41, 1.414, 1.4142...), just never exactly equal. The same proof works for √3, √5 and the square root of any whole number that isn't a perfect square.
