# Script A: Both even: contradiction

[HOOK] No fraction, however huge its numbers, equals the square root of two. {c3}
[MASCOT: Big enough numbers must work!] Surely some giant fraction works?
Suppose a over b works, in lowest terms. {c3}
[EQUATION: a² = 2b²] Then a squared equals two b squared, so a squared is even. {c3}
Odd numbers have odd squares, so a must be even: two k. {c2}
Then b squared is two k squared, so b is even too. {c2} {c3}
Both even means it wasn't in lowest terms, so no fraction works. {c3}
[TAKEAWAY] Root two is irrational: its decimal never ends or repeats. {c1} {c4}
